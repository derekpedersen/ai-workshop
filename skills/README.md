# Skills

This directory contains reusable capability modules for specific software delivery and AI workflow tasks.

## Included skills

- project-planning
- requirements-discovery
- architecture-design
- frontend-development
- backend-development
- code-review
- testing

Each skill should focus on a specific responsibility and be reusable across multiple workflows and agents.

The code-review skill is intentionally structured as a single capability with supporting review lenses for correctness, security, maintainability, and testing.
